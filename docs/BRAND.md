# Zumbra brand

Decided 2026-09-20 by the owner: the **Negative Z** eclipse mark, dark ground only. There is no
light-mode variant and none is planned; if the mark ever has to sit on a light surface it goes
on a void-coloured tile.

## The idea

*Umbra* is the full shadow, the part of an eclipse an observer cannot see into. The mark is a
disc of corona light with a Z cut out of it as true negative space: the letter is the shadow.
Nothing is drawn inside the Z; it is the ground showing through.

## Files

| File | What | Rule |
|---|---|---|
| `brand/mark.svg` | The mark. 512 viewBox, one gold circle, one masked Z. | Source of truth. Edit this and re-export; never hand-edit a PNG. |
| `brand/dist/` | Every exported asset (see sizes below) | Generated by `node brand/tools/export.mjs`. Committed so the site and README can link to them. |
| `brand/fonts/` | Inter ExtraBold, JetBrains Mono Medium (SIL OFL 1.1) | Used by the exporter. The site self-hosts the same families; it makes no third-party request. |
| `brand/explorations/` | The six constructions that were considered and the contact sheet | Record. Do not ship from here. |

## Tokens

| Token | Value | Use |
|---|---|---|
| `--void` | `#0B0D12` | Ground. Never pure `#000`. |
| `--gold` | `#F2C14E` | The corona. The only accent. One gold element per view is plenty. |
| `--pale` | `#F4F1EA` | Wordmark and primary text. Never pure `#fff`. |
| `--mist` | `#9AA3B2` | Secondary text, taglines. |
| `--moon` | `#1A1F2B` | Cards, rules, borders on void. |

Gold was chosen because a corona is warm and because Zcash's own mark is gold; the mark reads as
"in the Zcash family" without borrowing the shield.

## Type

- **Wordmark:** Inter ExtraBold (800), all caps, tracking 0.16 em. The leading Z in gold, the
  rest in pale. Rendered from live text on the site; rasterised by the exporter for images.
- **Labels and taglines:** JetBrains Mono Medium (500), all caps, tracking 0.14 em, mist.
- **Body:** Inter 400–500, pale on void.

## Construction rules

- Mark size minimum on screen: 16 px (favicon). At 16 the Z is still a Z; that is why this
  construction won over the others (see `brand/explorations/eclipse/contact-sheet-2026-09-20.png`).
- Clear space around the mark: one quarter of its width on every side.
- Lockup: mark, then wordmark, baseline of the wordmark at 70% of the mark's height, gap of
  one fifth of the mark's width. `brand/dist/lockup.svg` is the reference.
- Never: gradients on the mark, glows, outlines, drop shadows, a second colour, rotation, a cat.
- The tagline is **"Shielded Zcash for humans and agents"** until the product earns a better one.

## Voice

Short, technical, specific. State what shipped and what broke. Say "pre-alpha", "not yet" and
"not decided" without apology. Every claim maps to something that exists in the code today; a
tool count or a date is never written by hand. No hype words, no rockets, no "gm", no price, no
token talk on the wallet's surfaces. Credit the parent project plainly; never compare against it.
Never "audited", never "secure" as a bare adjective: say which specific thing holds.

Two registers on the site, one voice: human mode answers in prose, agent mode answers in real
command blocks. Both say the same true thing.
